# Style Extraction Axes

Run the registered specialist axes independently after routing: palette, medium signature, character design, lighting, composition, mood, background treatment, edge treatment, line quality, and surface texture. Each specialist must ground fields and rationale in the router assessment and source pixels. An inapplicable axis returns no extraction. A failed axis is isolated and recorded without cancelling sibling axes.
