# Action Timeline Reference Fidelity

Use an Asset reference run whenever prose identifies a cited subject, place, object, or source. Never invent an Asset id. Reuse the same reference consistently across separated beats when the same visible entity returns. References may point directly to images, video frames, audio, or documents; they never point to another Capability Artifact.
