# Research and Implementation Plans

This skill points to the canonical workflow instead of copying it.

- For research, feasibility work, vendor evaluation, architecture investigation, or another spike, read and follow `documentation/development-workflow/research-and-development/SPIKE-REPORT-GUIDELINES.md`.
- For an implementation plan, technical proposal, design doc, RFC, feature spec, detailed ticket, or implementation from an approved plan, read and follow `documentation/development-workflow/research-and-development/WRITING-IMPLEMENTATION-PLANS.md`.
- When a spike moves into implementation, read both guides and continue using the same file under `documentation/memory/`.

Read the applicable guide in full before drafting or changing the memory file. Follow the command rules linked from `documentation/development-workflow/AGENT-SKILLS.md` before running commands.
