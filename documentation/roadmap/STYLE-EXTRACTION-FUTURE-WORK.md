# Style Extraction Tool Future Work

The live implementation is documented in [Style Extraction Tool](../library/STYLE-EXTRACTION-TOOL.md). Storage and operational risks belong in [Capability Storage and Operations](../library/CAPABILITY-STORAGE.md).

## Deferred enhancements

- Multiple visual-style outputs from one extraction request.
- Semantic catalog search beyond normalized prefix and tags.
- Public marketplace publishing, moderation, ratings, and billing.
- Cross-organization Capability publishing.
- Usage analytics and per-Capability spend controls beyond existing provider metering.
- Confirmation interrupts for additional high-risk action classes.
- Dragging a Capability onto the canvas as a spatial workflow node.
- Capability revision history or user-visible rollback. The live system has one mutable definition and sealed per-run hashes.
