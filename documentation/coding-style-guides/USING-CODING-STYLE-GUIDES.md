# Using Coding Style Guides

Before writing or reviewing implementation code, inspect this directory and read every guide that applies to the languages or styling formats affected by the task.

A task may require more than one guide. For example, a Svelte component with TypeScript logic and SCSS styling requires both the TypeScript and Sass/CSS guidance.

New language or styling guides added to this directory are automatically part of this selection rule; no agent-skill catalog update is required.
