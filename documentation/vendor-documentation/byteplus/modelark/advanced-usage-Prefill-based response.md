When calling a model, you can steer and constrain its output using prefill\-based response: prefill part of the `assistant` message, and the model will continue generating from that content. This helps you guide the output toward your intended result.

You can use this mechanism in scenarios such as:


* **Enforcing a specific format**, for example JSON or XML.

* **Generating very long content** beyond the model’s maximum output length by continuing generation across multiple turns.

* **Maintaining role consistency** in role\-play scenarios.

## Key configuration

Set the `role` of the last message in the message list to `assistant`. The model will then continue generating based on the existing format and content of that `assistant` message.

```Python
messages = [
    {"role": "user", "content": "You are a calculator, calculate: 1 + 1"},
    # Message with the assistant role
    {"role": "assistant", "content": "="}
]
```

## Use case 1: Improve output formatting

The model may generate content based on its own interpretation, which can make the output hard for downstream programs to parse.

To steer the model to output a clean JSON object, you can prefill the `{` character so it skips non\-essential natural\-language text and continues directly with a JSON object.

This makes the response more concise, well\-structured, and easier to parse programmatically.

### Important notes


* ModelArk provides **Structured Output** capabilities that enable the model to return JSON that strictly conforms to your schema. For details, see [Structured Output](https://docs.byteplus.com/en/docs/ModelArk/1568221).

* Because model generation is probabilistic, a response cannot be guaranteed to be valid JSON in all cases. We recommend validating the output. The following example uses the [json_repair](https://github.com/mangiucugna/json_repair) library to check whether the returned content is a valid JSON object.

   ```Python
   import json
   # Install json-repair: pip install json-repair
   import json_repair
   import os
   # Install SDK:pip install byteplus-python-sdk-v2
   from byteplussdkarkruntime import Ark 
   
   PREFILL_PREFIX = "{"
   client = Ark(
       #The base URL for model invocation .
       base_url="https://ark.ap-southeast.bytepluses.com/api/v3", 
       # Get API Key: https://console.byteplus.com/ark/region:ark+ap-southeast-1/apikey
       api_key=os.getenv('ARK_API_KEY'), 
   )
   completion = client.chat.completions.create(
       #Replace with Model ID .
       model = "seed-1-8-251228",
       messages=[
           {"role": "user", "content": "List the name and function of the seed models launched by ByteDance in the JSON format"},
           {"role": "assistant", "content": PREFILL_PREFIX},
       ]
   )
   # Concatenate PREFILL_PREFIX and model output
   json_string = PREFILL_PREFIX + completion.choices[0].message.content
   # Parse JSON Object
   obj = {}
   try:
       obj = json.loads(json_string)
   except json.JSONDecodeError as e:
       obj = json_repair.loads(json_string)
   
   print(obj)
   ```

## Use case 2: Output beyond the length limit

Use prefill\-based response to have the model continue generating content based on the previous turn, and concatenate outputs across multiple calls to produce an ultra\-long response. This helps avoid incomplete results caused by the `max_tokens` (maximum output length) limit.

> However, this approach feeds the model’s output back into subsequent requests, which increases token usage.

> Add safeguards such as a maximum iteration limit to prevent edge cases (for example, infinite loops) that could lead to unexpected costs.


```Python
import os
# Install SDK:pip install byteplus-python-sdk-v2
from byteplussdkarkruntime import Ark 
  
messages = [
    {"role": "user", "content": '''Please translate the following text into English: ************ '''},
    {"role": "assistant", "content": ""}
]

#Replace with Model ID
ark_model="seed-1-8-251228"

client = Ark(
    #The base URL for model invocation
    base_url="https://ark.ap-southeast.bytepluses.com/api/v3", 
    # Get API Key: https://console.byteplus.com/ark/region:ark+ap-southeast-1/apikey
    api_key=os.getenv('ARK_API_KEY'), 
)

completion = client.chat.completions.create(
    model=ark_model,
    messages=messages
)

loop_count = 0 # Initialize loop counter
max_loops = 20  # Set maximum loop count to 20

# Trigger loop to generate assistant responses due to output length limitations
while completion.choices[0].finish_reason == "length":
    messages[-1]["content"] += completion.choices[0].message.content
    completion = client.chat.completions.create(
        model=ark_model,
        messages=messages
    )    
    # Increment counter
    loop_count += 1    
    # Check if maximum loop count is exceeded
    if loop_count >= max_loops:
        print(f"Warning: Reached maximum loop count {max_loops}, stopping content generation.")
        break

# Return the last response
messages[-1]["content"] += completion.choices[0].message.content
print(messages[-1]["content"])
```

## Use case 3: Improve role\-play consistency

We typically use **system messages** to define role instructions. However, as the conversation grows longer, the model may drift from the intended persona.

With prefill\-based response enabled, you can remind the model of the role it should follow in the current output, helping keep responses consistent and aligned with your expectations.

```Python
import os
# Install SDK:pip install byteplus-python-sdk-v2
from byteplussdkarkruntime import Ark 

client = Ark(
    #The base URL for model invocation
    base_url="https://ark.ap-southeast.bytepluses.com/api/v3", 
    # Get API Key: https://console.byteplus.com/ark/region:ark+ap-southeast-1/apikey
    api_key=os.getenv('ARK_API_KEY'), 
)
#Replace with Model ID
ark_model="seed-1-8-251228"

messages = [
    {"role": "system", "content": "The following is a scene from Journey to the West. Please converse according to the specified role. For each round of dialogue, only reply with the content of the current role; do not add any additional content.\n\nAfter leaving Wuzhuang Guan, Tang Seng and his disciples traveled for more than a month and arrived at the foot of a great mountain. Wukong looked around and saw lofty mountains, steep ridges, overgrown weeds, and extremely dangerous terrain."},
    {"role": "assistant", "content": "Wukong said:"}
]

completion = client.chat.completions.create(
    model=ark_model,
    messages=messages
)
print(messages[-1]['content']+completion.choices[0].message.content)
```


Example response:

```text
Wukong said: "Master, this mountain looks extremely dangerous. I will go scout the path first. You all wait here for a moment."
```
